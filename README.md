# Sahay: Smart Roadside Assistance

## What it does
- Connects stranded drivers with nearby mechanic shops
- Customers raise breakdown requests with live location and track status in real time
- Shops accept, complete or reject requests and get email alerts
- Admin manages shops and requests, views analytics and downloads PDF reports
- Sevak: offline chatbot covering 50+ roadside problems

## Tech used
- **Backend:** Java 17, Spring Boot 3, Spring Security, Spring Data JPA
- **Database:** MySQL 8
- **Frontend:** HTML, CSS, JavaScript
- **Maps:** Leaflet.js + OpenStreetMap
- **Email:** JavaMail (Gmail SMTP)
- **Build and deploy:** Maven, Docker, Render
